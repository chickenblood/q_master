Design Philosophy

Dark-first. Designed for pre-dawn eyes. Light mode available via Settings.
One accent. F3 Red for all actions, states, labels.
Angular. 8 px radius — utility over decoration.
Larger. 18 px list, 19 px navbar, 68 px setup rows.
Section previews. Workout items show sections inline.
All flows baked in. Unified entry, detail, setup-first timer, drag-handle picker, grouped settings.
